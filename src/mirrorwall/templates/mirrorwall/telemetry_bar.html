{# mirrorwall/telemetry_bar.html — a fixed-width readout of a generic telemetry payload. Every field starts as an em dash, and the JS module replaces it only where a value was actually reported. It never renders 0 for an absent reading (UI standards §3): a machine that could not measure its GPU temperature did not measure it as zero degrees. `telemetry_field_meters` (design brief §4, §5) opts a field group into the artboard's inline track — `["cpu", "ram", "gpu", "vram"]` for the dense console. It is off by default because design.md §6 is explicit that nothing in 0.3 changes an application's rendering until that application asks: an app that never passes it renders exactly the bar it rendered under 0.2.2. The track carries no `role="meter"` and no width until telemetry.js has a real percentage, so an unsupported reading (ADR-0016) shows an empty track beside its em dash, never a full bar and never a bar sitting at zero. #} {%- set field_meters = telemetry_field_meters | default([]) %}
